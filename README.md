# imagepool

Public image host for images used in my articles.

Images are served over GitHub's raw CDN. URL pattern:

```
https://raw.githubusercontent.com/Affan-sajid/imagepool/main/<folder>/<filename>
```

## AirTalk

46 figures (`f01`–`f46`). Example:

```markdown
![Who this is for](https://raw.githubusercontent.com/Affan-sajid/imagepool/main/AirTalk/f01-who-this-is-for.png)
```
